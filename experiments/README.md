# Evidências, experimentos e saídas

- `evaluation/`: comparações com MapBiomas, ablações, sensibilidade de limiares e inspeção visual.
- `outputs/`: arquivos GeoJSON, imagens PNG, GeoTIFFs e métricas de diferentes versões do pipeline.

São **artefatos históricos**; a API sempre roda a classificação de verdade para novas análises. Não se deve usar resultados prontos como resposta ao upload. Os artefatos estão versionados para auditoria e reprodução dos números citados na nota.
